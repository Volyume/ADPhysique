Design review · 16 November 2026

Volyume and Astryx, Meta's design system

What Astryx is, whether Volyume can use it, which of its ideas would make the app noticeably better, and three screens redrawn to show it.

The short answer

Can't install it

Astryx is a web toolkit

Its components are React for web browsers (react-dom, CSS custom properties, StyleX). Volyume is React Native. The React Native version is a written proposal (spec AST-112, phase "proposed") with no code. The native package is canary-only, labelled "Nothing here is supported for production apps", and so far only draws six components in SwiftUI for iPhone.

Don't swap the look

Volyume's own tokens are stronger

Volyume's theme already has contrast-tested light, dark, higher-contrast and colour-blind-safe palettes. Astryx's seven themes (Neutral, Butter, Chocolate, Matcha, Stone, Gothic, Y2K) are general-purpose looks. Adopting one would lose the amber identity and the accessibility work.

Borrow the rules

Its design principles are the real value

Eight years of Meta use is written down as plain design rules: one strong action per group, space before boxes, nested corners that match, one edge style per surface. Volyume breaks several of these today. The licence is MIT, so ideas and values can be reused freely, with no new dependency.

Worth adopting, best first

Each one is a design rule, not a package. All can be done with Volyume's existing theme file and components.

One filled button per group

The main action on a card gets a solid amber fill. Everything next to it steps down to a quiet fill or plain text. Today "Start workout" looks the same as "Options", and "Set it up" looks the same as "No thanks", so the eye has nowhere to land.

Astryx: color-emphasis DR3, "Emphasis remains scarce"

Space first, boxes second

Group related rows into one filled list with hairline dividers instead of a separate bordered card each. Drop card borders and let the surface ladder (background, surface, raised) show depth, which is what Volyume's own materials policy already says for the dark theme. Last session and Challenge become two rows of one list; Meal 1 to Meal 4 stop being four empty cards.

Astryx: spatial-hierarchy DR3, elevation-hierarchy DR3, "One edge language leads"

Corner radius named by role

Add role names (inner, element, container, page) alongside the size names, and make nested corners concentric: inner radius equals outer radius minus padding. Inputs inside a 20 radius card with 12 padding get about 8 to 10, not a separate guess.

Astryx: shape-relationships DR1 and DR2

Fill-only inputs in the workout logger

Weight and rep boxes lose their outline and use a fill. Done sets fade back, the current set gets a soft amber band. Under gym lighting and fast thumbs, the current set is then the brightest thing on screen.

Astryx: user-states and control-rhythm DR2, "Size and density are tuned together"

Motion timing by weight

Small feedback (a tick, a chip) is quick; whole sheets and screens take longer and settle. Volyume already has motion tokens and Reduce Motion support; this is a rule for choosing between them.

Astryx: motion DR2, "Weight determines timing"

Not worth taking

  • The components. They are web-only, and Volyume already has native versions of the mobile ones.
  • The seven themes. They would replace the amber identity and lose the colour-blind and higher-contrast palettes.
  • The CLI and "agent-ready" tooling. It reads Astryx's own docs, so it adds nothing without the components.

If you want to go ahead

The three concepts need no new package and no change to the coaching engine or the safety rules. The work is in Volyume's own theme file and shared components:

  • Theme: add role-named radius values and a "quiet fill" button style next to the existing tokens.
  • Shared components: a grouped list with dividers, and a compact prompt row that the Today offers can use.
  • Screens: Today, the workout logger and the nutrition diary, one at a time, each checked on device at the largest text size.

The calm-mode and ED-flag behaviour on Today and Nutrition (hidden counts, no weight figures, no higher-calorie day under a flag) would carry over unchanged, since only the presentation moves.
