# EVIDENCE DOSSIER TEMPLATE (gap-closure order section 12; GC-D5)

One dossier per population-specific or injury-specific profile that
carries evidence-informed content beyond pure function. Machine-readable
convention: every dossier uses EXACTLY these 21 numbered fields, in this
order, each as a `## N. <name>` heading; `profileId:` on line 3 binds it
to the in-app directory profile; field 19 uses the section 27 status
ladder vocabulary. A dossier is REQUIRED before any population-labelled
collection ships (FD-3, GC-D5); fields 12, 20 and 21 are the claim
gates.
