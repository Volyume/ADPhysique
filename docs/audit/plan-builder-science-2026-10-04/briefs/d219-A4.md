# D219 lane A4: swaps, one-off or permanent, same sets and reps (design 4.12)

Read first: d219-build-common.md; design ../00-AUDIT-AND-PLAN.md sections 1.6 and 4.12; register D219 (the founder: "When people swap in a workout can they get an option to swap as a one off or permanent. Also when doing swaps the new exercise should have the same sets and reps ideally so we don't misplace load"). Plan facts and serving: src/lib/sessionAdjustments.js (buildPlanSessions reads facts.slots[routineId][exerciseId] = { muscle, kind, credits }), src/lib/plan/catalogue.js (catalogueCredits).

Build:
1. Every swap surface (in-session in ActiveWorkoutScreen, the plan's routine screen, and any other; list them) offers "Just this session" or "From now on". One-off changes only that session's logged exercise; the plan is untouched.
2. The new exercise takes the slot's sets, reps and effort (the prescription carried); rest and load per Campaign 16 job 7 as the design says. Same-muscle alternatives are offered first.
3. A permanent swap on a plan whose facts are version 2 updates facts.slots for that slot (the new exercise's muscle, kind by the generator's key, credits by catalogueCredits or {}), so every week is served on the planner's model; where the new exercise trains a different primary muscle, a calm note says the slot's sets now count for that muscle.
4. Tests, each failing on today's code first: the scope choice on every surface; sets and reps carried; one-off leaves the plan unchanged; permanent updates the routine and the facts; serving after a permanent swap stays inside the caps.

Do not touch: coachApply.js, src/lib/plan/** except reading, the check-in card and src/lib/plan/checkinPlacement.js (lane A3), sync. database.js: add or change only the swap functions. STOP and report on any ambiguity.
