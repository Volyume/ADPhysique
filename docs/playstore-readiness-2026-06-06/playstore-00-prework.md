## The single most important structural fact

`android/` and `ios/` are **gitignored** (`.gitignore` lines `/android/`,
`/ios/`). `git ls-files android` returns 0. This is an **Expo CNG (prebuild)
project**: the native projects are generated by `expo prebuild` at build time
from `app.json` + the config plugins, and EAS regenerates them on every build.

Consequences that govern every fix in this audit:

- The committed `android/app/build.gradle` (showing `versionCode 9`,
  `versionName "1.1.1"`, debug signing, minify off) is a **stale generated
  artifact**. It is not the source of truth and editing it does nothing — the
  next prebuild overwrites it.
- The real native config lives in: `app.json`, `eas.json`, `babel.config.js`,
  `metro.config.js`, and `plugins/*.js`. **Every Phase 9 fix must land there**,
  never in `android/`.
- The committed `android/app/src/main/AndroidManifest.xml` is likewise a stale
  prebuild snapshot. It is read here only to see what libraries inject; the
  authoritative permission set is `app.json` + library plugins.
