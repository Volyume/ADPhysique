# Copy Library

Approved, claim-cited copy lives here by surface:

- **store/** — Google Play listing copy (description, short description, feature bullets)
- **web/** — volyume.app website copy (landing page, article headers, CTAs)
- **social/** — Short-form posts for Instagram, TikTok, X, Reddit, YouTube
- **community/** — Forum/community platform copy (Reddit posts, Slack community guidelines)
- **email/** — Transactional and promotional email copy

**Every line cites the PRODUCT-FACTS entry backing it.**

- **pending-review/** — Drafts awaiting the compliance gate
- **needs-fix/** — Failed items with the cited reasons
